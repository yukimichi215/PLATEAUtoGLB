PLATEAUtoGLB（Windows 版）

■ 使い方
  PLATEAUtoGLB.exe をダブルクリックすると起動します。インストールは不要です。
  好きなフォルダに置いて使ってください（消すときは exe を削除するだけです）。

■ 必要なもの
  ・Windows 10 / 11（64ビット）
  ・インターネット接続（PLATEAU のデータと住所検索をその場で取得します）
  ・Microsoft Edge WebView2 ランタイム（Windows 10/11 には通常入っています）

■ 初めて起動するとき
  署名のないアプリのため、「Windows によって PC が保護されました」と出ることがあります。
  この exe が GitHub の自分のリポジトリの自動ビルドから取ったものであることを確かめてから、
  「詳細情報」→「実行」を押してください。

■ データの出典
  建物・道路のデータは国土交通省 Project PLATEAU の3D都市モデル（各自治体が著作権を保有）です。
  作った GLB と一緒に保存されるクレジットの文章を、PlotBlock の素材のクレジット欄に貼ってください。
  このアプリは国土交通省・自治体のものではありません。
